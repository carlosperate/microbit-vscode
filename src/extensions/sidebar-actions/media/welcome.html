Welcome to the BBC micro:bit IDE

Write code, send it to a BBC micro:bit, and watch it run. MicroPython or C++ projects, all in the browser.

Explore these 5 IDE features
1Open or create a project

This is a small starter project, with main.py ready to edit in the Explorer. To work on your own code, open a folder from your computer or start a fresh MicroPython or C++ project.

2Send it to the micro:bit

Plug the micro:bit in over USB and press Build & flash. It uses WebUSB, so you need a Chrome-based browser such as Chrome or Edge. Pair once, when asked, and every flash after that goes straight through.

3Watch it run

No board to hand? The MicroPython simulator runs your code in the browser. On real hardware, whatever your program prints, and every error, comes back over the serial terminal.

4Keep what you make

Files in this tab vanish when you close it. Switching storage opens a fresh workspace rather than moving files, so pick browser storage or a folder on your computer before you start anything you want to keep.

5Pick a look

Six micro:bit themes, three light and three dark. Change again any time from the Command Palette.
